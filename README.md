# A股强势股量化筛选 V2.0（第一阶段）

本项目是**可运行的初筛原型**，尚未完成真实数据回测、板块资金分析、完整市场覆盖验证或盘中实时行情。

## 使用

```bash
pip install -r requirements.txt
python screener.py --limit 100
streamlit run app.py
```

默认只扫描符合条件的前100只股票用于验证；如需全市场扫描，执行 `python screener.py --limit 0`，耗时长且可能触发接口限流。

输出 `results.csv` 和 `results.csv.status.json`，后者记录失败数量及部分错误。价格过滤使用行情快照，日线可能不同步；停牌、退市、数据异常需人工复核。

## 核心规则

沪深主板、非ST、股价低于50元；近三日上涨、后两日缩量回调、5/10/20日均线多头、守住10日均线。评分为规则匹配分数，**没有统计意义上的胜率或预期收益保证**。本版未加入基本面、板块强度和外部因素。

## 数据与风险

使用 AkShare 封装的公开数据接口，可能受网络、限流、字段调整影响。复权数据可能变化。仅用于研究，不构成投资建议。
